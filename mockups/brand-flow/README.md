# Brand flow mockup

Static, clickable mockup of the business-side flow. No backend; everything is scripted.

Your product → brand research (TinyFish) → choose a creator video → review placements (approve / disapprove per moment) → Campaigns (Drafts / In review / Live).

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server -d mockups/brand-flow 8000
```

Frames in `frames/` are from Tears of Steel (Blender Foundation, CC BY 3.0), downscaled from `artifacts/suggest/tears_of_steel/frames/`.
